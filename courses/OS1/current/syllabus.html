Course Objectives

By the end of this course, you will be able to:

  • Explain why modern operating systems need to support multiple programs running at once, and describe how they are structured.
  • Use system calls correctly and confidently in your programs.
  • Understand the difference between processes and threads, and choose the right abstraction for a given problem.
  • Identify and fix problems that arise when multiple programs run concurrently.
  • Explain how files work and how programs perform I/O at the system level.
  • Compare different methods for inter-process communication and choose the appropriate one.
  • Write system-level programs that apply the concepts and techniques covered in this course.
