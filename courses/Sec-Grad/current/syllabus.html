Textbooks

No required textbook. Reading materials will be provided on the course website and/or distributed in class.

Prerequisites

This course requires a basic understanding of computer systems and computer security. Please consider taking these courses first:

  • CS 312 :: Linux System Administration (must)
  • CS 370 :: Introduction to Security (must)
  • CS 374 :: Operating Systems I (recommended)
  • CS 434 :: Machine Learning and Data Mining (recommended)

Grading

Your final grade for this course will be based on the following scheme:

  • 20%: Written paper critiques [Details]
  • 15%: In-class paper presentation [Details]
  • 50%: Term-project [Details]
  • 15%: Final Exam [Canvas, Take-home]

  • [Bonus] ~10%: Extra point opportunities
    • +5%: Outstanding project work
    • +5%: Submitting term-project to workshops (at the instructor's discretion)
